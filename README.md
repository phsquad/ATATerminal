# ALEXANDER TALENTS AGENCY (ATA) // TERMINAL: СОЦИАЛЬНЫЙ ЛИФТ 2026

Кибернетический терминал закрытого опроса спонсоров и рецензентов фонда **«Социальный Лифт»** с защитой от накруток, аппаратными спец-ключами и трансляцией результатов в реальном времени.

Разработано для статического хостинга **GitHub Pages** в связке с облачной БД **Supabase** (PostgreSQL + Realtime).

---

## 🛡 Архитектура доступа и защита от накруток

Терминал разделяет аудиторию на две категории:

1. **Обычные посетители (Режим Наблюдателя / Read-Only):**
   - Могут свободно просматривать витрину кандидатов, читать хирургические досье, цитаты, выжимки и следить за распределением голосов в реальном времени.
   - **Кнопка голосования заблокирована** плашкой `[🔒 ТРЕБУЕТСЯ КЛЮЧ СПОНСОРА]`.

2. **Авторизованные участники (Спец-ключи доступа):**
   - **Спонсоры (SPONSOR):** Меценаты, поддержавшие резервный фонд агентства (10 236 монеток).
   - **Активные Рецензенты (CRITIC):** Участники сообщества, регулярно комментирующие и пишущие разборы работ.
   - **Защита 72 часа (1 раз в 3 дня):** Каждый спец-ключ привязан к персональному таймеру. Попытка проголосовать повторно раньше 3 суток блокируется как на клиенте (бегущий таймер обратного отсчета), так и на уровне базы данных PostgreSQL.

## ➕ Как генерировать новые ключи для спонсоров в Supabase

Чтобы выдать новый ключ реальному спонсору, который задонатил монетки, достаточно выполнить один SQL-запрос в **Supabase SQL Editor**:

```sql
insert into public.voter_keys (key_code, holder_name, role, coins_donated)
values ('SPONSOR-IVAN-2026', 'Иван Меценат', 'SPONSOR', 300);
```

Для активного комментатора:
```sql
insert into public.voter_keys (key_code, holder_name, role)
values ('CRITIC-ANNA-READER', 'Анна (Рецензент)', 'CRITIC');
```

## 🚀 Деплой на GitHub Pages за 1 минуту

1. Загрузите файл `index.html` в корень вашего репозитория на GitHub.
2. В репозитории откройте **Settings -> Pages**:
   - Выберите ветку `main` (или `master`) и папку `/ (root)`.
   - Нажмите **Save**.
3. Сайт откроется по ссылке: `https://<ваш-аккаунт>.github.io/<репозиторий>/`.

## 🗄 Настройка Supabase (3 минуты)

1. Создайте проект на [supabase.com](https://supabase.com).
2. Откройте **SQL Editor** и выполните содержимое файла `supabase_setup.sql`.
   - Скрипт создаст таблицы `candidates`, `votes`, `voter_keys` и зарегистрирует функцию `cast_lift_vote_with_key`.
3. В **Project Settings -> API** скопируйте `Project URL` и `anon public key`.
4. В самом терминале на сайте нажмите **«⚙️ НАСТРОЙКИ СВЯЗИ»** (шестеренка в футере или настройках) и вставьте параметры.
